## 구성
- `index.html` 한 파일로 동작합니다(외부 라이브러리 없음, 글꼴만 Google Fonts). AI 채점만 별도의 채점 서버(Google Apps Script 웹앱 → Gemini API)를 호출하며, 인터넷이 없으면 채점 외의 기능은 그대로 쓸 수 있습니다.
- **홈**: 학생 / 교사 선택
- **학생**: 논·서술형 응시 화면 (1번 중1 반티 업체, 2번 중2 주말 야외 행사)
  - 공통 제시자료 고정, 조건, 문항별 제시자료, 기호·분수·그리기 입력, 밑줄·형광펜·메모장, 임시저장, 화면 구성 번호(01~07) 보기
  - **제출하고 AI 채점 받기**: 별명과 접속 코드를 넣고 제출하면 AI(Gemini)가 채점기준표·예시답안에 따라 채점 요소별 점수·채점 근거·피드백을 바로 보여 줌(글 답안, 그리기 답안 모두). 연수 시연용 채점이며 실제 시스템의 채점 결과가 아님
  - **이 문항 AI 채점**: 전체를 제출하지 않고도, 지금 보고 있는 하위 문항 하나만 바로 채점받을 수 있음(같은 세트 앞 문항 답안은 참고용으로만 함께 보냄). 별명을 한 번 적으면 다음부터는 버튼 한 번으로 채점
  - **채점기준표와 견주어 보기**: 채점 결과 창에서 누르면 AI가 채점에 쓴 채점기준표(점수별 수행 특성·예시답안)가 옆 창으로 떠서, AI가 준 점수 줄과 채점 근거를 기준표와 나란히 확인(교사 미리보기 채점에서는 고친 기준표가 뜸)
  - **같은 답안 다시 채점**: 채점 결과 창에서 누르면 같은 답안·같은 기준표로 한 번 더 채점해 처음 결과 아래에 나란히 보여 줌(문항당 3회까지). 점수가 달라진 채점 요소는 색으로 표시해, 기준표 문장이 모호한 곳을 찾는 데 씀
  - **예시 채점 결과**: 인터넷이나 채점 서버가 안 될 때를 대비해, 예시 답안 6개를 미리 채점해 둔 결과가 화면에 들어 있음. 제출 창의 ‘예시 채점 결과’ 또는 채점 실패 안내의 ‘예시 채점 결과 보기’로 열며, 기준표 견주어 보기도 그대로 됨
  - 별명·답안·채점 결과는 연수 진행자의 구글 스프레드시트에 기록됨(실명·개인정보는 쓰지 않음). 접속 코드는 연수 진행자가 안내
- **교사**: 문항 입력·편집
  - 기본 정보 / 문항(지시문·제시자료·발문) / 조건 / 채점기준표 / 예시답안 / 피드백 탭
  - 학생 화면 미리보기, 자동 점검(배점 합, 0점 진술, 예시답안 개수·형태, 조건 지시 등)
  - 미리보기 마지막 문제의 **AI 채점 해 보기**: 방금 고친 채점기준표로 바로 채점해, 기준표 문장을 바꾸면 채점이 어떻게 달라지는지 확인(결과에 ‘교사 편집 기준표’ 표시, AI가 기준표를 모호하다고 본 곳은 색으로 표시)
  - **고치기 전·후 나란히 보기**: 미리보기에서 고친 기준표로 채점한 뒤 결과 창의 ‘고치기 전(기본) 기준표로도 채점해 나란히 보기’를 누르면, 같은 답안을 기본 기준표로 한 번 더 채점해 두 결과를 한 표에 나란히 보여 줌(점수가 달라진 채점 요소 색 표시, 달라진 기준표 문장을 고치기 전·후로 표시)
  - 편집 내용은 브라우저(localStorage)에 저장, ‘문항 데이터 복사·붙여넣기’로 다른 컴퓨터에 옮김
- **채점기준 비교 실습**: 0번 예제 2개(예1 일차방정식 0.2(x−2)=1 4점, 예2 소수·분수 계수 연립방정식 5점)와 2025 2학년 서술형 1~3(소문항 9개)의 기존 풀이과정 기준(⋯[1점])과 AI용 채점기준표(점수별 수행 특성·대표 오답·예시답안)를 나란히 비교
  - 소문항마다 5단계로 안내: 문항 읽기 → 기존 기준표(같은 답안 채점해 보기) → AI용 점수 칸 → AI용 예시답안 → 정리·협의
  - 소문항마다 ‘AI용으로 바꾸며 글로 꺼낸 것’과 ‘채점 협의로 미리 정할 것’, 배점 불일치·그림 답안 표시
  - 2단계 ‘직접 해 보기’에서 초안을 쓰고 4단계에서 AI용 예시와 나란히 비교(초안은 브라우저에 저장)
  - 0번 예제: 같은 답안을 두 기준표로 채점한 비교표 포함(예2는 세부 채점 요소 ‘정리하기 2점 + 풀기 3점’)
  - 공통 규칙 6가지(동치 표현, 이월 오류, 감점 규칙 공개, 개수로 묶기, 그림 답안, 예시답안)

- **채점 기준 바꿔 보기 안내**: 기준표를 고쳐 AI 채점이 달라지는 것을 확인하는 순서, 해 볼 만한 실험 3가지(덧붙일 문장·적을 답안·실제 채점 결과), 결과 창 읽는 법, 알아 둘 점. 처음 화면과 교사 화면에서 열거나 주소 끝에 `#rubtry`

- **출제 프로토콜**: ① 학년·단원·성취기준 정하기 → ② 문항 구체화하기 → ③ 채점 기준표 작성하기 → ④ 예시 답안 작성하기 → ⑤ 시스템에 문항 탑재하기 (소단계 14개, 할 일·따라 하기(중2 주말 야외 행사)·점검 질문·우리 검토에서 나온 실수·내 문항 메모), 한 장 요약과 워크시트 인쇄
- **K-DOT 출제 매뉴얼**(서울 참고자료) 여섯 마당: K-DOT 5수준과 기존 모형 비교, 수학 교과 수행 요소, 수준 맞히기 9문항, 문항 개발 6단계·문항 정보 양식, 작성 원칙(서울 vs 인천 비교), 매뉴얼 수학 예시 문항(중1 대푯값) 해설
- 교사 편집: 문항별 사고 수준(K-DOT)·수행 요소 입력, 자동 점검에 K-DOT 원칙(추상적 표현, 12점 초과) 추가

## 연수 당일 도구 (2026. 10. 16. 추가)
- **오늘의 연수** (`#today`): 10. 17.(토) 13:00~17:00 중학교 분반의 네 시간 흐름(제안)과 시간대별 바로가기, 접속 QR
- **예시답안 교차 채점** (`#cross`): 실습 자료집의 학생 A·B·C 답안(중1 반티 문항 1·3)을 모둠(1~10조)이 채점 요소별로 채점하고 판단 근거와 함께 저장
  - 채점 요소마다 점수 버튼과 ‘채점기준 보기’(점수별 기준 문장), 학생 C는 판단이 갈리는 쟁점 3개(인정/불인정)도 함께 저장
  - **AI 채점 결과 보기**: 같은 채점 서버·기본 기준표로 연수 전에 3번씩 채점해 둔 결과(세 번 모두 같았는지 표시)와 모둠 점수를 나란히, 다른 칸은 색 표시. 현장에서 다시 채점도 가능
  - **해설·예상 점수 보기**: 출제자 해설판의 예상 점수, 요소별 판단 근거, 쟁점별 인정/불인정 논리, 채점 협의 포인트(진행자 안내 뒤에 열도록 확인 창)
  - 모둠을 ‘시험’으로 고르면 리허설 기록으로 따로 쌓여 현황판에 섞이지 않음
- **모둠 채점 현황판** (`#board`): 모든 모둠의 마지막 저장을 모아 채점 요소별 점수 분포·일치 비율·AI 점수, ‘협의할 곳 먼저 보기’(판단이 갈렸거나 AI와 다른 요소), 쟁점 판단 비율, 모둠별 합계, 모둠별 판단 근거, 해설 함께 보기, 15초 자동 새로 고침, CSV 내려받기, 현황판 비우기(시트 백업 탭으로 복사 후)
- 학생 화면 **그리기 입력**에 펜·지우개·되돌리기 추가(기존 전체 지우기 유지)
- 휴대폰에서 아래쪽 이전/다음 버튼이 ‘연수 가이드’·글자 크기 버튼에 가리던 문제 수정
- 처음 화면에 ‘연수용 모형’ 안내 띠와 새 화면·설명서 바로가기

## 연수 도우미
- 화면 왼쪽 아래 **연수 가이드**: 처음 화면(5단계)·학생 화면(10단계)·교사 화면(9단계) 둘러보기(스포트라이트), 연수 활동 8가지(직접 해 보면 자동 체크)
- **가− / 100% / 가+**: 글자 크기 5단계(90~140%), 브라우저에 기억됨
- 주소 끝에 `#guide`를 붙이면 가이드가 열린 채로, `#compare`는 채점기준 비교 실습, `#kdot`는 K-DOT 안내, `#proto`는 출제 프로토콜, `#rubtry`는 채점 기준 바꿔 보기, `#today`·`#cross`·`#board`는 연수 당일 도구로 시작
