# AI 논·서술형 평가 연수 시연

2026 인천 AI 논·서술형 평가지원시스템 실천교사(심화과정) 중등 수학 개발 문항을 입힌 **연수 시연용 모형 화면**입니다. 실제 교육청 서비스가 아닙니다.

> ⚠️ 시스템용 문항·채점기준표·예시답안이 들어 있습니다. 공개 범위에 유의하세요.

**바로 보기**: GitHub Pages가 켜져 있으면 `https://j333333766-hub.github.io/ai-essy-demo/` 에서 열립니다.

## 구성
- `index.html` 한 파일로 동작합니다(외부 라이브러리 없음, 글꼴만 Google Fonts).
- **홈**: 학생 / 교사 선택
- **학생**: 논·서술형 응시 화면 (1번 중1 반티 업체, 2번 중2 주말 야외 행사)
  - 공통 제시자료 고정, 조건, 문항별 제시자료, 기호·분수·그리기 입력, 밑줄·형광펜·메모장, 임시저장, 화면 구성 번호(01~07) 보기
- **교사**: 문항 입력·편집
  - 기본 정보 / 문항(지시문·제시자료·발문) / 조건 / 채점기준표 / 예시답안 / 피드백 탭
  - 학생 화면 미리보기, 자동 점검(배점 합, 0점 진술, 예시답안 개수·형태, 조건 지시 등)
  - 편집 내용은 브라우저(localStorage)에 저장, ‘문항 데이터 복사·붙여넣기’로 다른 컴퓨터에 옮김
- **채점기준 비교 실습**: 0번 예제 2개(예1 일차방정식 0.2(x−2)=1 4점, 예2 소수·분수 계수 연립방정식 5점)와 2025 2학년 서술형 1~3(소문항 9개)의 기존 풀이과정 기준(⋯[1점])과 AI용 채점기준표(점수별 수행 특성·대표 오답·예시답안)를 나란히 비교
  - 소문항마다 5단계로 안내: 문항 읽기 → 기존 기준표(같은 답안 채점해 보기) → AI용 점수 칸 → AI용 예시답안 → 정리·협의
  - 소문항마다 ‘AI용으로 바꾸며 글로 꺼낸 것’과 ‘채점 협의로 미리 정할 것’, 배점 불일치·그림 답안 표시
  - 2단계 ‘직접 해 보기’에서 초안을 쓰고 4단계에서 AI용 예시와 나란히 비교(초안은 브라우저에 저장)
  - 0번 예제: 같은 답안을 두 기준표로 채점한 비교표 포함(예2는 세부 채점 요소 ‘정리하기 2점 + 풀기 3점’)
  - 공통 규칙 6가지(동치 표현, 이월 오류, 감점 규칙 공개, 개수로 묶기, 그림 답안, 예시답안)

- **출제 프로토콜**: ① 학년·단원·성취기준 정하기 → ② 문항 구체화하기 → ③ 채점 기준표 작성하기 → ④ 예시 답안 작성하기 → ⑤ 시스템에 문항 탑재하기 (소단계 14개, 할 일·따라 하기(중2 주말 야외 행사)·점검 질문·우리 검토에서 나온 실수·내 문항 메모), 한 장 요약과 워크시트 인쇄
- **K-DOT 출제 매뉴얼**(서울 참고자료) 여섯 마당: K-DOT 5수준과 기존 모형 비교, 수학 교과 수행 요소, 수준 맞히기 9문항, 문항 개발 6단계·문항 정보 양식, 작성 원칙(서울 vs 인천 비교), 매뉴얼 수학 예시 문항(중1 대푯값) 해설
- 교사 편집: 문항별 사고 수준(K-DOT)·수행 요소 입력, 자동 점검에 K-DOT 원칙(추상적 표현, 12점 초과) 추가

## 연수 도우미
- 화면 왼쪽 아래 **연수 가이드**: 처음 화면(5단계)·학생 화면(10단계)·교사 화면(9단계) 둘러보기(스포트라이트), 연수 활동 8가지(직접 해 보면 자동 체크)
- **가− / 100% / 가+**: 글자 크기 5단계(90~140%), 브라우저에 기억됨
- 주소 끝에 `#guide`를 붙이면 가이드가 열린 채로, `#compare`는 채점기준 비교 실습, `#kdot`는 K-DOT 안내, `#proto`는 출제 프로토콜로 시작

## 사용
`index.html`을 내려받아 브라우저로 열면 됩니다.
